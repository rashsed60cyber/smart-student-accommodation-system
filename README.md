# Smart Student Accommodation and Mess Management System

### Software Engineering Capstone Project | Semester 3.1

A web-based student accommodation discovery and management platform designed to help university students find suitable mess accommodations and assist mess owners in managing their properties efficiently.

## 1. Project Overview

The **Smart Student Accommodation and Mess Management System** is a React-based web application that simplifies the process of searching, comparing, and managing student accommodations.

Students can explore available mess listings, compare different accommodation options, and receive recommendations based on their preferences.

The system also provides dedicated interfaces for mess owners, administrators, and university proctors to support accommodation management and student welfare.

## 2. Problem Statement

University students often face difficulties finding suitable accommodation due to limited information about rental prices, location, facilities, availability, and safety.

Traditional accommodation searching requires visiting multiple locations, communicating with different owners, and comparing options manually.

This project aims to address these challenges through a centralized web-based accommodation management platform.

## 3. Project Objectives

- Develop a user-friendly student accommodation searching platform.
- Allow students to explore and compare mess accommodations.
- Provide accommodation recommendations based on student preferences.
- Enable mess owners to manage accommodation listings.
- Support student complaints and university proctor review workflows.
- Improve access to accommodation information.

## 6. Software Development Methodology

The **Incremental Software Development Model** is selected for the capstone project.

The system is divided into different functional modules so that each module can be developed, evaluated, and improved separately.

### Proposed Development Phases

1. Requirement analysis and project planning
2. System design and UML modeling
3. Student accommodation search and comparison module

5. Recommendation and complaint management modules

## 10. Project Installation

### Requirements

- Node.js
- npm
- A modern web browser

### Installation Steps

Clone the repository:

```bash
git clone https://github.com/rashsed60cyber/smart-student-accommodation-system.git
```

Navigate to the project folder:

```bash
cd smart-student-accommodation-system
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal.

### Production Build

```bash
npm run build
```

## 11. Current Prototype and Limitations

The current project is a client-side web application prototype.

Some application data and workflows rely on browser-based storage. A production-ready version would require a secure backend, persistent database, and server-side access control.

The proposed domain class architecture is part of the system design and must be verified against the implemented application before being described as fully completed.
